# DashFlow AI Agent

Submission for Microsoft AI Hackathon 2025

### DashFlow AI Agent an AI agentic tool built for deeper automation and intelligence. It allows users to integrate with any database and generate contextual insights based on natural language queries. DashFlow accelerates decision-making by eliminating the need for manual data querying or report generation.

DashFlow:
- Natural language query interface
- Smart database connectors (SQL, NoSQL, cloud DBs)
- AI-driven insight generation and summarization
- Embeddable and customizable agent workflows
